Chaves do lembrete diário

Gera as chaves que a função lembrete-diario do Supabase usa para enviar notificações. Tudo é feito aqui no seu navegador: nada é enviado para lugar nenhum.

Gere uma vez só. Se gerar de novo e trocar no Supabase, os aparelhos precisam ativar as notificações de novo. Não coloque estas chaves no GitHub nem mande para ninguém.

VAPID_PUBLIC_KEY
VAPID_PRIVATE_KEY
LEMBRETE_SEGREDO

Deixe esta aba aberta até terminar os passos no Supabase.
